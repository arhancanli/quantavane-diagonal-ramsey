## 2. The extended bank

Our certificate adds to P0r12 new controls, new raw and closed profiles and new source pairs. A new object may refer
to old ones (children, terminal sources, raw profiles in closed pieces, profiles in source cells); old objects never
refer to new ones. The union is a finite bank in the sense of (Z3): every old object keeps its realisation (its
hypotheses do not mention the new objects), and every new object has a realisation that our checkers verify. By
Theorem 5.7 all claims of the union hold with one constant C_*, and Corollary 5.10 applies to our new root.

What the certificate (cert JSON, format of code/checkA/runA.py) contains, as generated by search/materialise.py
(written 17 Nov 12:0x +04):
- New RAW profiles at densities j/80 or j/160, knots on the grid (5 + i)/400, each piece one leaf or one retained
  route (Def. 5.4). The generator built them in rounds; a round-q object refers only to ZBS objects, to new objects
  of earlier rounds, to closed objects U_q' (q' <= q) and to source pairs; U_q' is built from ZBS raw profiles and raw
  profiles of rounds < q'. So the dependencies are acyclic (Theorem 5.7 would also allow cycles).
- New CLOSED profiles U_q (density 1/10^6), each piece a complementary pair of RAW profiles (Def. 5.5(2)). Def. 5.5
  places no condition on p_Q for a complementary pair (every host has red density >= p_R or blue density >= p_S
  when p_R + p_S <= 1, whatever p_Q is; ZBS's ClosedPF.complRaw check has no p_Q term, and ZBS's own bank uses closed
  profiles at density 1/80). Used as a route child, U_q needs only a slope d > -log(1 - 10^-6) (condition (12)); in the
  proof of Lemma 5.8 the child's density enters only through eta_0 = min(1 - p_c - e^{-d}) > 0 (REFEREE_20261117.md).
  This is the one
  parameter choice outside ZBS's practice (their least closed density is 1/80); referees should look at it.
- New SOURCE pairs (A, B): left tail and right tail by single ZBS tangent lines (condition (13) of ZBS via
  f-hat <= c + d lam, Z4), cells grounded (one tangent line at both cell ends) or complementary pairs of profiles.
- New CONTROLS (p, mu, w, beta, x, lxU, l1mL): CtrlD.ok of ZBS plus a Lemma C certificate (Section 3) for
  CERT < 0, checked by our two Python checkers (not by a proof kernel); beta = 1 - 10^-7; terminal data (xi, nu, y0 slack, aU, bU) per piece as in ZBS's TermF.
- The ROOT: a raw profile R at density 1/2 with domain [1 - 2 delta, 1 + 2 delta], delta = 10^-10, constant height z,
  one retained route piece; and a closed profile Q on [1 - delta, 1 + delta] with knots (1 - delta, z), (1, z),
  (1 + delta, z(1 + delta)) rounded up, one complementary-pair piece (R, R) (p_R + p_R = 1). Then
  L_Q >= max(L_R(r), r L_R(1/r)) on the piece, and Corollary 5.10 gives R(k,k) <= ceil(C_* e^{k L_Q(1)}),
  L_Q(1) = z.  Hence R(k,k) <= (e^z + o(1))^k.

## 3. Lemma C (certificate for CERT < 0); the only new mathematics

Fix p, mu, beta in (0,1), w > 0, 0 < x < min{p, (1-mu)^w}. For q in (0, mu] put
A(q) = ((1-q)/q) log(p (1-q)^w / x), B(q) = w log(mu/q), U = e^{beta B},
G0(q) = q log p + beta q (A(q) - B(q)),  D = {q in (0,1) : G0(q) < 0},
and M, Q, CERT as in ZBS Section 3.2. Let H(q) = q M(q) + w q.

(i) Q = D cap (0, mu]. If A <= B then p e^{beta A} <= p U < U, so q is in D; conversely the second branch of
    Q is exactly p e^{beta A} < U, i.e. G0 < 0.
(ii) G0 is convex on (0,1): G0(q) = beta w [q log q + (1-q) log(1-q)] + q log p + beta (1-q) log(p/x)
    - beta w q log mu (expand q A(q) and q B(q)). Hence D is an interval, and if G0(a) >= 0 > G0(mu) for some
    a < mu then mu is in Q and Q is contained in (a, mu].
(iii) H is concave on D (EP Section 5, "Certifying the local envelope"). With z = G0(q)/q, f(z) = p z + (1-p) log
    (1 - e^z) and fbar(z) = f(max{z, log p}):  H(q) = q B(q) + w q + (q/beta) [fbar(G0(q)/q) - f(log p)].
    [Check: if A <= B then z <= log p and the bracket is 0, M = B; if A > B, with y = beta(A - B) = z - log p,
    beta (M - B) = p y + (1-p) log((1 - p e^y)/(1-p)) = f(z) - f(log p).]  q B(q) = w q log(mu/q) is concave;
    fbar is concave and nonincreasing on z < 0 (f'(z) = (p - e^z)/(1 - e^z) <= 0 for z >= log p, f'' < 0, and
    fbar' is continuous at log p with value 0); its perspective (q, y) -> q fbar(y/q) is jointly concave and
    nonincreasing in y, and G0 is convex, so q -> q fbar(G0(q)/q) is concave. The remaining terms are linear.
(iv) Secant majorant: for u < v in D and q in D outside (u, v), H(q) <= H(u) + (H(v) - H(u))(q - u)/(v - u)
    (concavity). Let a = q_0 < q_1 < ... < q_N = mu. Suppose for each cell [q_i, q_{i+1}] a secant through grid
    points u < v of D lying on one side of the cell (v <= q_i or u >= q_{i+1}) is at most h_i at q_i and at most
    h_{i+1} at q_{i+1}. Then for q in Q cap [q_i, q_{i+1}] and every real s,
    H(q) + w q s <= T(q) + w q s <= max{h_i + w q_i s, h_{i+1} + w q_{i+1} s} (T the secant, affine in q).
    So sup_{q in Q} [q M(q) + w q (1 + log t)] <= max_i (h_i + w q_i log t) for t in (0, 1].
(v) If h_j <= h_k for all j > k then for log t <= 0 the lines j > k are dominated by line k (no larger value at
    log t = 0 and no smaller slope), so the maximum may be taken over i <= k. With D_i = w (q_{i+1} - q_i) > 0 and
    r_i = (h_i - h_{i+1})/D_i, line_{i+1} - line_i = D_i (log t - r_i), hence
    max_{i<=k} line_i(log t) <= line_0(log t) + sum_{i<k} D_i (log t - r_i)_+, and since
    int_0^1 (log t - r)_+ dt <= e^r - r - 1 (equality for r <= 0, and 0 <= e^r - r - 1 for r > 0),
    CERT(p, mu, w, beta, x) <= h_k - w q_k + sum_{i<k} D_i e^{r_i}   (telescoping; EP eq. (5.2)).
    The integrand of CERT, t -> sup_{q in Q} [H(q) + w q (1 + log t)], is a finite convex function of log t (a
    supremum of affine functions of log t, finite since Q is bounded and nonempty), hence measurable; it is bounded
    below by its value at q = mu (in Q), which is integrable, and above by the hinge function, so it is integrable.
Conclusion: if G0(a) >= 0 > G0(mu), the secant conditions of (iv), the dominance of (v) and
h_k - w q_k + sum_{i<k} D_i e^{r_i} < 0 hold, then Q is nonempty and CERT < 0, i.e. (Z2) applies.

Checker A evaluates H by the two-branch formula of ZBS; checker B by the representation in (iii). Both enclose every
exp/log with outward rounding (A: own dyadic intervals, 256 bits; B: Arb balls, 320 bits) and use exact rationals
elsewhere.
