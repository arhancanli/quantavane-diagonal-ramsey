## (a) Lemma C, line by line: OK

Setting: A(q) = ((1-q)/q) log(p(1-q)^w/x), B(q) = w log(mu/q), U = e^{beta B}, G0(q) = q log p + beta q (A - B).

1. Expansion of G0 (PROOF line 65-66). OK.
   q A(q) = (1-q) log(p/x) + w (1-q) log(1-q);  q B(q) = w q log mu - w q log q. Hence
   G0 = q log p + beta[(1-q) log(p/x) + w(1-q) log(1-q) - w q log mu + w q log q]
      = beta w [q log q + (1-q) log(1-q)] + q log p + beta (1-q) log(p/x) - beta w q log mu,
   exactly the formula in (ii). The bracket is convex on (0,1), beta w > 0, the rest is affine, so G0 is convex on
   (0,1) and D = {G0 < 0} is an open interval. (Float check at three smoke controls: max error 3e-16.)

2. Q = D cap (0, mu] (line 63-64). OK, exactly.
   For q > 0, G0(q) < 0 <=> log p + beta(A - B) < 0 <=> p e^{beta A} < e^{beta B} = U. If A <= B then
   p e^{beta A} <= p U < U, so q is in D; if A > B, membership in ZBS's second branch is exactly p e^{beta A} < U.
   Conversely every q in D cap (0, mu] is in one of the two branches. If G0(a) >= 0 > G0(mu) with a < mu, then
   mu is in Q and, D being an interval containing mu but not a, Q is contained in (a, mu].

3. H = qM + wq concave on D (line 68-74). OK.
   Identity: with z = G0(q)/q = log p + beta(A - B), f(z) = p z + (1-p) log(1 - e^z), fbar(z) = f(max{z, log p}):
   - branch A <= B: z <= log p, fbar(z) = f(log p), bracket 0, H = qB + wq = qM + wq;
   - branch A > B (ZBS's second branch, valid on Q): y = z - log p > 0, U - p e^{beta A} = U(1 - p e^y), so
     beta(M - B) = beta p A + (1-p)[beta B + log((1 - p e^y)/(1-p))] - beta B = p y + (1-p) log((1-p e^y)/(1-p))
     = f(z) - f(log p) because e^z = p e^y.
   So H(q) = q B(q) + w q + (q/beta)[fbar(G0(q)/q) - f(log p)] on Q, and the right side is defined on all of D (the
   derivation never uses q <= mu). (Float check: identity error <= 8e-13; the domains of the two formulas agreed at
   60,000 random points.)
   Concavity: f'(z) = (p - e^z)/(1 - e^z), f'(log p) = 0, f''(z) = -(1-p) e^z/(1 - e^z)^2 < 0; so fbar equals the
   constant max f(log p) left of log p and f right of it: concave and nonincreasing on z < 0. Its perspective
   g(q, y) = q fbar(y/q) is jointly concave on {q > 0, y < 0} and nonincreasing in y. For q1, q2 in D and
   lambda in [0,1]: G0(q_lambda) <= lambda G0(q1) + (1-lambda) G0(q2) < 0, so q_lambda is in D and
   g(q_lambda, G0(q_lambda)) >= g(q_lambda, lambda G0(q1) + (1-lambda) G0(q2)) >= lambda g(q1, .) + (1-lambda) g(q2, .).
   q B(q) = w q log mu - w q log q is concave; the rest is linear. Hence H is concave on D. (Float check: no discrete
   concavity violation on a 40,000-point grid at three controls.)

4. Secant majorant (line 75-80). OK.
   For u < v in D and q in D outside (u, v), concavity gives H(q) <= T(q), T the extended chord. If the chord's grid
   points satisfy v <= q_i or u >= q_{i+1}, every q in Q cap [q_i, q_{i+1}] lies outside (u, v). T(q) + w q s is
   affine in q, so it is at most the larger of its values at q_i and q_{i+1}, hence at most
   max{h_i + w q_i s, h_{i+1} + w q_{i+1} s}. Since Q is inside (q_0, q_N], every point of Q lies in some cell, and
   with s = log t: sup_Q [qM + wq(1 + log t)] = sup_Q [H(q) + w q log t] <= max_i (h_i + w q_i log t).
   h_i must bound BOTH chords that meet at q_i (cell i-1 at its right end, cell i at its left end); both checkers
   test every cell at both of its nodes against h[node], which does exactly this.

5. Dominance (line 81-82). OK. If h_j <= h_k for all j > k and log t <= 0, then
   h_j + w q_j log t <= h_k + w q_k log t because q_j > q_k and w log t <= 0. Valid for every t in (0, 1].

6. Hinge bound (line 82-86). OK.
   l_{i+1}(s) - l_i(s) = (h_{i+1} - h_i) + w(q_{i+1} - q_i) s = D_i (s - r_i), so for m <= k,
   l_m = l_0 + sum_{i<m} D_i (s - r_i) <= l_0 + sum_{i<k} D_i (s - r_i)_+  (D_i > 0).
   int_0^1 l_0(log t) dt = h_0 - w q_0. For r < 0: int_{e^r}^1 (log t - r) dt = e^r - r - 1; for r >= 0 the integral
   is 0 <= e^r - r - 1. Telescoping: sum_{i<k} D_i(-r_i - 1) = (h_k - h_0) - w(q_k - q_0), so
   CERT <= h_0 - w q_0 + sum_{i<k} D_i (e^{r_i} - r_i - 1) = h_k - w q_k + sum_{i<k} D_i e^{r_i}. Correct.
   Float check (three smoke controls, brute-force sup over a 40,000-point q grid, 3,000-point t quadrature):
   hinge bound -1.405e-4 vs CERT ~ -1.423e-4; -5.161e-5 vs -5.333e-5; -3.542e-6 vs -6.649e-6. The bound is above CERT
   as it must be.

7. Integrability (line 87-88). OK, one sentence missing. Lower bound mu M(mu) + w mu (1 + log t) is integrable
   (int |log t| = 1); upper bound the hinge function, integrable. Measurability is not stated: add that the integrand
   is a supremum of functions affine in s = log t, bounded above, hence a finite convex function of s, hence continuous
   in t on (0,1). (If this is ever ported to Lean, where the Bochner integral of a non-integrable function is 0, this
   sentence becomes a real obligation.)

## (b) The extended bank: OK

1. Theorem 5.7 applies to any finite bank. Its statement (tex 917-921) and proof (1001-1036) use only finiteness
   (K, M_I, c_0 = min_h min(A_h, B_h), C_prof, C_small, epsilon = min_h min(epsilon_h, eta_h)) and the conditions of
   Definitions 5.1-5.6; nothing refers to P0r12. The Lean development agrees: BankF.diagonal (V5Fast 873-877) is
   generic in F : BankF nCtl m nR nC. Old objects keep their realisations because their data mention only old
   objects. Cycles would also be allowed (every child, terminal source and stopping rule is used on a proper subset;
   closed profiles use direct claims on the same host, which are established first in Stage 1, then sources in
   Stage 3).

2. Closed complementary pair at density 1e-6 (Definition 5.5(2), Lemma 5.9). Legitimate. Definition 5.3 only needs
   p_Q in (0,1); Definition 5.5(2) puts no condition on p_Q; the proof of Lemma 5.9 says so in its last sentence
   ("The complementary case does not use d_R(V) >= p_Q"). The Lean check ClosedPF.complRaw (V5Fast 603-606) has no
   p_Q term. Closed profiles as route children are ZBS practice (D20.lean has 748 calls to closed profile 537 alone);
   only the density value is new. ZBS's least closed density is 1/80 (checked in zbs_bank.json).

3. As a route child (Definition 5.4, condition (12)) with slope d > -log(1 - 1e-6). Legitimate. In the proof of
   Lemma 5.8 the child's density enters only through eta_0 = min_j (1 - p_c(j) - e^{-d_j}) > 0 (tex 960), used to get
   (1 - p_c)(|Z| - 1) >= e^{-d}|Z| once |Z| >= 1/eta_0 (tex 981), and through K_J (eta_0 e^{k psi_min - V_d} >= 1).
   A tiny eta_0 only makes K_J larger; K_J and D_J stay independent of C. Nothing needs the child's density to be on a
   grid or bounded below. The checkers enforce (12) as e^{-d} <= z < 1 - p_c (strict at the second step), identical
   to Lean's cellCheck. One note: for a child valid at every density, (12) and the route inequality force
   L_P(r) > psi(r) > L_U(r), so U can only help through the terminal term; that is a matter of usefulness, not
   validity.

4. Minor wording (not an error): Section 2 says the new objects form a DAG but also that round-q raw objects refer to
   U_q. That is a DAG only if U_q's pairs use ZBS or earlier-round raw profiles. In smoke_cert.json U_0 uses only ZBS
   raw profiles (1,570 references, all 'zr'), so it is a DAG there. Say this explicitly or drop the DAG remark (cycles
   are allowed anyway).

## (c) The root: OK

Q on J = [1 - delta, 1 + delta], one complementary-pair piece (R, R), p_R + p_R = 1 <= 1. Domains: J is inside
I_R = [1 - 2 delta, 1 + 2 delta]; {1/r : r in J} = [1/(1+delta), 1/(1-delta)] is inside I_R because
1/(1+delta) >= 1 - delta >= 1 - 2 delta and 1/(1-delta) = 1 + delta + delta^2/(1-delta) <= 1 + 2 delta. Inequality:
L_R = z constant, so max(L_R(r), r L_R(1/r)) = max(z, r z): equal to z on [1-delta, 1] (knots (1-delta, z), (1, z))
and r z on [1, 1+delta], where L_Q is the chord from (1, z) to (1+delta, Z) with Z >= z(1+delta), hence >= r z. The
reflected knots of R (near 1 +- 2 delta) are outside J, so the breakpoint list {1-delta, 1, 1+delta} suffices.
Corollary 5.10 applies (Q combined, 1 in I_Q, the piece containing 1 is a complementary pair) and gives
R(k,k) <= ceil(C_* e^{z k}) for every k >= 1, with C_* the constant of the union bank and z = L_Q(1) = L_R(1).
Hence R(k,k) <= (e^z + o(1))^k. Two side remarks: (i) the ZBS Lean diagonal theorem uses a different root test
(BankF.rootCheck: p_root <= 1/2, 1 in domain, L(1) < z strictly), which R itself already passes, so Q is not even
needed; (ii) any headline "b^k" needs a certified e^z <= b, which neither runner computes yet (both print z_float).
