## 0. The two claims and exactly what each rests on

### 0.1 Statements

**Theorem 1 (certK3; within ZBS's framework).** Assume the results of ZBS listed in 0.3 (A). Then there is a constant
C_* >= 1 such that for every k >= 1

    R(k,k) <= ceil(C_* e^{z1 k}),   z1 = 1248056263241/10^12 = 1.248056263241,

and e^{z1} <= 8708913097/2500000000 = 3.4835652388. Hence R(k,k) <= 3.4835653^k for all sufficiently large k.

**Theorem 2 (certCD3; within ZBS's framework, with Theorem A of this document).** Assume the results of ZBS listed in
0.3 (A) and (B). Then there is a constant C_* >= 1 such that for every k >= 1

    R(k,k) <= ceil(C_* e^{z2 k}),   z2 = 311946616731/250000000000 = 1.247786466924,

and e^{z2} <= 278610041/80000000 = 3.4826255125. Hence R(k,k) <= 3.4826256^k for all sufficiently large k.

C_* is not effective (it comes from Theorem 5.7, whose proof uses Theorem 3.4, a compactness argument; for Theorems 1U
and 2U through Section 16 (P3.3) and the compactness steps of Section 14 (P1.2), Section 6 and Section 17 (Lemma B.1')).
The previous best bound is EP's R(k,k) <= 3.49135655^k for large k (z = 625145177/500000000 = 1.250290354;
github.com/EvolvingPrograms/DiagonalRamsey at 959f46b0, 1 Nov 2026). In z, Theorem 1 is 2.234e-3 below EP and

## 1. ZBS's framework: what is used, quoted

### 1.1 Notation (ZBS Section 2.1)

A host is a red/blue colouring of the edges of a complete graph on a finite set V. For disjoint X, Y, d_R(X, Y) is
the proportion of red X-Y edges; d_R(V) = e_R(V)/binom(|V|, 2), d_B(V) = 1 - d_R(V). V ⊇ (a, b) means V contains a red
K_a or a blue K_b. Renaming the colours exchanges red density d with 1 - d and targets (a, b) with (b, a).

### 1.2 The local-step functions (ZBS Section 3.2, quoted)

"Fix 0 < p < 1, 0 < mu < 1, w > 0, 0 < beta < 1 and x > 0. For q in (0, mu] let

    A(q) = ((1-q)/q) log(p (1-q)^w / x),   B(q) = w log(mu/q),   U(q) = e^{beta B(q)} = (mu/q)^{w beta}.

Let M(q) = B(q) if A(q) <= B(q), and otherwise

    M(q) = p A(q) + ((1-p)/beta) log((U(q) - p e^{beta A(q)})/(1-p)).

[...] the feasible set F = F(p, mu, w, beta, x) is the set of q in (0, mu] with A(q) <= B(q), or with A(q) > B(q) and
p e^{beta A(q)} < U(q). When F is nonempty we define

    CERT(p, mu, w, beta, x) = int_0^1 sup_{q in F} [ q M(q) + w q (1 + log t) ] dt.

On F one has M(q) <= B(q), by concavity of the logarithm, so the integrand is bounded above. The statement CERT < 0
includes the assertion that the integrand is integrable."

### 1.3 Theorems 3.4 and 4.2 (ZBS, quoted)

Theorem 3.4 (sharp envelope). "Let 0 < p < 1, 0 < mu < 1, w > 0, 0 < beta < 1 and 0 < x < min{p, (1-mu)^w}. Suppose
F is nonempty and CERT(p, mu, w, beta, x) < 0. Then there are eta, tau, zeta > 0 and R_0 with R_0 > w and beta R_0 > 1
such that, for every r >= R_0, there is no configuration consisting of a host on V, a simple graph B on V, disjoint
nonempty X, Y in V and a real c with |c - p| <= eta, such that (i) g_y > c for every y in Y; (ii) (X, Y) is maximal for
Phi_c with parameters w, r, s = beta r; (iii) every i in X with q_i > 0 fails blue; (iv) there is X_g in X with
|X \ X_g| <= zeta |X| such that every i in X_g has q_i <= mu + tau and fails shifted-red."
(Phi_c(X, Y) = |X|^w |Y| H_c(X, Y)^r with H_c = (E_Y (g_y - c)_+^s)^{1/s}; "fails blue" and "fails shifted-red" are
ZBS's (2) and (3).)

Definition 4.1 (stopping rule). "A host on V satisfies Stop(C, xhat, yhat, l) if, for every integer a >= 1, every
proper subset Z of V with |Z| >= C xhat^{-a} yhat^{-l} contains a red K_a or a blue K_l."

Theorem 4.2 (finite-host closure). "Let 0 < p < 1, 0 < mu < 1, w > 0, 0 < beta < 1 and 0 < x < min{p, (1-mu)^w}, and
suppose F is nonempty and CERT(p, mu, w, beta, x) < 0. Let xi, y0, nu, xhat, yhat in (0, 1) satisfy xi < min{x, xhat},
y0 < yhat, nu < mu. Then there is an integer L_0, depending only on these ten numbers, with the following property.
Let C >= 1, let l >= L_0, and let a host on V satisfy Stop(C, xhat, yhat, l). Let k, t >= 1 be integers and X, Y in V
disjoint and nonempty with d_R(X, Y) >= p, |X|^w |Y| >= C^{w+1} xi^{-k} y0^{-l} nu^{-w t}. Then X cup Y contains a red
K_k, or X contains a blue K_t, or Y contains a blue K_l."

### 1.4 Banks (ZBS Definitions 5.1-5.6, quoted; TeX of zbs_main.tex lines 821-912)

Definition 5.1 (source pairs). "A bank has finitely many source pairs (A_h, B_h) with A_h, B_h > 0. Each pair stands
for the claim (SOURCE_h) |V| >= C e^{A_h k + B_h b} => V ⊇ (k, b) for all integers k, b >= 1. We write
T_h(lambda) = A_h + B_h lambda."

Definition 5.2 (controls). "A control is a tuple gamma = (p, mu, w, beta, x; sigma; xi, y0, nu) with 0 < p, mu, beta < 1,
w > 0, 0 < x < min{p, (1-mu)^w}, F nonempty, CERT(p, mu, w, beta, x) < 0, a source index sigma, and
0 < xi < min{x, e^{-A_sigma}}, 0 < y0 < e^{-B_sigma}, 0 < nu < mu. We write p_gamma = p, w_gamma = w, and
A_gamma = -log xi, B_gamma = -log y0, b_gamma = -log nu."

Definition 5.3 (profiles). "A profile P = (p_P, I_P, L_P) has a density p_P in (0, 1), a compact interval I_P in
(0, infinity), and a positive continuous piecewise-affine function L_P on I_P with finitely many rational knots. With
constant C >= 1, it stands for the claim (ASSERT_P) d_R(V) >= p_P and |V| >= C e^{k L_P(b/k)} => V ⊇ (k, b), for all
integers k, b >= 1 with b/k in I_P and every host V."

Definition 5.4 (direct realizations). "Each direct profile P has a finite cover of I_P by closed intervals J. Each J
carries a margin eps_J > 0 and one of the following.
1. Leaf. A control gamma with p_gamma <= p_P, such that on J
   L_P(r) >= eps_J + (A_gamma + r (B_gamma + w_gamma b_gamma))/(1 + w_gamma).
2. Retained route. A control gamma with pi := p_gamma < p_P; a partition theta = u_0 < u_1 < ... < u_M = omega with
   theta > 0 and J in [theta, omega]; for each cell J_j = [u_{j-1}, u_j] a slope d_j and a child profile c(j) (any direct
   or combined profile of the bank) with J_j in I_{c(j)}; and the continuous function psi on [theta, omega] with
   psi(theta) > 0 that is affine with slope d_j on J_j. These must satisfy
       (12)   d_j > -log(1 - p_{c(j)}),   psi(s) > L_{c(j)}(s)  (s in J_j),
   and, writing A, B, b, w for A_gamma, B_gamma, b_gamma, w_gamma, on J
       L_P(r) >= eps_J + max( psi(r), (A + r B + w (theta b + psi(r) - psi(theta)))/(1 + w) )."

Definition 5.5 (combined realizations). "Each combined profile Q has a finite cover of I_Q by closed intervals J, each
carrying one of the following. Only direct profiles are used in these combinations, and the inequalities are
non-strict. 1. Density copy. A direct profile R with p_R <= p_Q, J in I_R and L_Q >= L_R on J. 2. Complementary pair.
Direct profiles R, S with p_R + p_S <= 1, J in I_R, {1/r : r in J} in I_S and L_Q(r) >= max(L_R(r), r L_S(1/r)) on J."

Definition 5.6 (source covers). "For each source pair h fix 0 < l_h < H_h and eps_h, eta_h > 0 with
    (13)   f-hat(lambda) <= T_h(lambda) - eps_h (1 + lambda)   (lambda in (0, l_h] cup [H_h, infinity)),
and a finite cover of [l_h, H_h] by closed intervals J. Each J is either grounded, with f-hat <= T_h - eta_h (1 + lambda)
on J, or carries two profiles P_R, P_B with p_{P_R} + p_{P_B} <= 1, J in I_{P_R}, {1/lambda : lambda in J} in I_{P_B} and
max(L_{P_R}(lambda), lambda L_{P_B}(1/lambda)) <= T_h(lambda) - eta_h (1 + lambda) (lambda in J)."

### 1.5 Theorem 5.7, Lemmas 5.8-5.9, Corollary 5.10 (ZBS, quoted)

**Theorem 5.7 (bank validity), verbatim.** "Consider a bank whose direct profiles, combined profiles and source pairs
have realizations and covers as above. Then there is C_* >= 1 such that, with C = C_*, every claim (ASSERT_P) and every
claim (SOURCE_h) holds for every host."

ZBS add: "The dependencies between profiles and sources may form cycles. The theorem is still true because every
dependency is used on a strictly smaller host. The proof is an induction on the number of vertices of the host."
The statement quantifies over ANY finite bank with realizations and covers as in Definitions 5.4-5.6; nothing in it or
in its proof refers to the particular bank P0r12. Its proof uses the controls only through Lemma 5.8.

Lemma 5.8 (leaves and routes). "For each leaf or route piece J of a direct profile P there are K_J >= 1 and D_J >= 1,
depending only on the data of the piece and not on C, with the following property. Let V satisfy P_V(C), and fix a
naming of the colours. If k >= K_J, b/k in J, d_R(V) >= p_P and |V| >= D_J C e^{k (L_P(b/k) - eps_J/2)}, then
V ⊇ (k, b)." (P_V(C): every bank claim with constant C holds on every proper subset of V under both namings.) Its proof
uses the control only through: the stopping rule from (SOURCE_sigma); the hypotheses of Theorem 4.2 on
(xi, y0, nu, xhat = e^{-A_sigma}, yhat = e^{-B_sigma}), which give L_0(gamma); and the conclusion of Theorem 4.2.

Lemma 5.9 (combined profiles on the same host). "Suppose every direct claim holds on the host V, under both namings of
the colours. Then every combined claim holds on V." Its proof of the complementary case "does not use d_R(V) >= p_Q".

**Corollary 5.10 (diagonal bound), verbatim.** "Suppose a combined profile Q has 1 in I_Q, and the piece of Q containing
1 is a complementary pair. Then R(k,k) <= ceil(C_* e^{k L_Q(1)}) for every k >= 1."

### 1.6 The Lu-Wang input (ZBS Section 2.2, quoted)

f(t) = (1+t) log(1+t) - t log t + t e^{-t} P(t) on [0, 1], P the piecewise cubic Hermite interpolant of Lu-Wang's 2,280
rational knots (their data/source.json, SHA-256 f3e4a4ea...c08c); f-hat(lambda) = f(lambda) for 0 < lambda <= 1 and
lambda f(1/lambda) for lambda >= 1; f-hat(a, b) = a f-hat(b/a).
Theorem 2.2 (Lu-Wang uniform source bound). "For every eps > 0 there is C_eps >= 1 such that, for all integers a, b >= 1
and N, N >= C_eps exp(f-hat(a, b) + eps (a + b)) => N -> (a, b)."
Lemma 2.3: f-hat is concave on (0, infinity); so every exact tangent line lies above it. The 1,128 rational lines used
by ZBS's bank and by our new sources are majorants of tangents; their global validity is the Lean theorem
lu_wang_lines_P0r12 of 0.3 (A), not a statement of ZBS's paper.

## 2. The extended bank and the root (why Theorem 5.7 and Corollary 5.10 apply)

A certificate adds to P0r12 new controls, new raw (direct) profiles, new closed (combined) profiles and new source
pairs. New objects may refer to ZBS's objects and to each other; ZBS's objects never refer to new ones.

Claim 2.1. If every new object satisfies the corresponding clause of Definitions 5.2, 5.4, 5.5 or 5.6 (with all its
references resolved inside the union), then the union of P0r12 and the new objects is a bank satisfying the hypothesis
of Theorem 5.7.
Proof. Theorem 5.7's hypothesis is a conjunction over the objects of the bank: each direct profile has a realization
(Definition 5.4), each combined profile has one (Definition 5.5), each source pair has a cover (Definition 5.6), and
every control used is a control (Definition 5.2). For a ZBS object this is ZBS's certified statement (0.3 (A), last
item): its realization refers only to ZBS objects, which are still in the union with the same data. For a new object it
is what the checkers verify (Section 5) together with Lemma C (Section 3) for each new control. The bank is finite.
Cycles are allowed by Theorem 5.7; the generator in fact produces an acyclic dependency order (rounds), which is not
needed. []

The root. The certificate names a closed profile Q (field root.closed) and a rational z (field root.z). Both checkers
verify that every piece of Q whose interval contains 1 is a complementary pair (Definition 5.5(2)) and that
L_Q(1) = z exactly. By Theorem 5.7 and Corollary 5.10, R(k,k) <= ceil(C_* e^{z k}) for every k >= 1 (ZBS's versions;
or our restated versions, Section 16, whose proviso min_h min(eps_h, eta_h) > 7.57e-15 holds for the full certificates:
the minimum is 5e-13, Section 18.3). Then both checkers
enclose e^z with outward rounding and print an upper bound (checker A: a rational rounded up at 10 decimals; checker B:
an Arb ball). In certK3 and certCD3 the root is built as follows (by the generator, search/materialise.py; the checkers
verify only the conditions above): a raw profile R of density 1/2 on [1 - 2 delta, 1 + 2 delta], delta = 10^-10, one
retained-route piece; a closed profile Q on [1 - delta, 1 + delta] with one complementary-pair piece (R, R)
(p_R + p_R = 1). Corollary 5.10 needs no density condition on Q.

A parameter outside ZBS's practice. The generator's closed profiles U_q have density 10^-6 (ZBS's least closed density
is 1/80). Definition 5.3 allows any density in (0, 1); a closed profile built from complementary pairs is valid
whatever its density (Lemma 5.9's proof of the pair case does not use d_R(V) >= p_Q); used as a route child it needs
only d_j > -log(1 - 10^-6) in (12), and in the proof of Lemma 5.8 the child's density enters only through
eta_0 = min_j (1 - p_{c(j)} - e^{-d_j}) > 0. (Raised by us for the referee in research/tier2/ramsey-zbs/PROOF.md
Section 2; accepted in REFEREE_20261117.md (b).)

## 3. Lemma C: a finite certificate for CERT < 0 (new; proved here)

Source: research/tier2/ramsey-zbs/PROOF.md Section 3 (SHA-256 e2817877...9cc415), refereed in REFEREE_20261117.md
item (a), "OK" (no mathematical error).

Fix p, mu, beta in (0, 1), w > 0 and 0 < x < min{p, (1-mu)^w}. For q in (0, 1) put

    A(q) = ((1-q)/q) log(p (1-q)^w / x),   B(q) = w log(mu/q),   U = e^{beta B},
    G0(q) = q log p + beta q (A(q) - B(q)),   D = {q in (0, 1) : G0(q) < 0},   H(q) = q M(q) + w q

(M as in 1.2, defined where its logarithm is defined). Note G0(q) = q (log p + beta A - beta B).

**Lemma C.** Let a_cut = q_0 < q_1 < ... < q_N = mu (N >= 2) be rationals, k in {0, ..., N}, and h_0, ..., h_N
rationals. Suppose:
 (C-i)   G0(q_0) >= 0 and G0(mu) < 0;
 (C-ii)  for every cell i (0 <= i < N) there are grid indices u < v with v <= i or u >= i + 1, such that the secant
         line T_i of H through (q_u, H(q_u)) and (q_v, H(q_v)) satisfies T_i(q_i) <= h_i and T_i(q_{i+1}) <= h_{i+1}
         (all grid points used here lie in D, which the evaluation of H certifies);
 (C-iii) h_j <= h_k for all j > k;
 (C-iv)  h_k - w q_k + sum_{i<k} D_i e^{r_i} < 0, where D_i = w (q_{i+1} - q_i) and r_i = (h_i - h_{i+1})/D_i.
Then F(p, mu, w, beta, x) is nonempty and CERT(p, mu, w, beta, x) < 0.

Proof.
(i) F = D ∩ (0, mu]. If A <= B then G0 = q (log p + beta (A - B)) < 0 (log p < 0), so q is in D; if A > B, the
    condition p e^{beta A} < U = e^{beta B} is exactly log p + beta A < beta B, i.e. G0 < 0. Conversely if G0(q) < 0
    and A > B then p e^{beta A} < U. So F = {q in (0, mu] : G0(q) < 0}.
(ii) G0 is convex on (0, 1): expanding q A(q) and q B(q),
       G0(q) = beta w [q log q + (1-q) log(1-q)] + q log p + beta (1-q) log(p/x) - beta w q log mu,
    a sum of a convex function and affine terms. Hence D is an open interval. With (C-i): mu is in D, so mu is in F,
    and F is contained in (a_cut, mu] (a convex function that is >= 0 at a_cut and < 0 at mu is >= 0 on (0, a_cut]).
(iii) H is concave on D. Put z = G0(q)/q, f(z) = p z + (1-p) log(1 - e^z) for z < 0, and fbar(z) = f(max{z, log p}).
    Then H(q) = q B(q) + w q + (q/beta) [fbar(G0(q)/q) - f(log p)]. [If A <= B then z <= log p, the bracket is 0 and
    M = B. If A > B, with y = beta (A - B) = z - log p > 0, beta (M - B) = p y + (1-p) log((1 - p e^y)/(1-p))
    = f(z) - f(log p), because e^{beta B} - p e^{beta A} = e^{beta B}(1 - p e^y).] Here q B(q) = w q log(mu/q) is
    concave. f'(z) = (p - e^z)/(1 - e^z) is <= 0 for z >= log p and f'' < 0, so fbar is concave and nonincreasing on
    (-infinity, 0) (constant on z <= log p, with f'(log p) = 0, so fbar is C^1 at log p). Its perspective
    (q, y) -> q fbar(y/q) is jointly concave on q > 0 and nonincreasing in y; G0 is convex; a jointly concave function
    nonincreasing in its second argument, composed with (q, G0(q)), is concave. The other terms are linear.
(iv) Secant majorant. For u < v in D and q in D outside (u, v), concavity gives H(q) <= T(q), T the secant through
    (u, H(u)) and (v, H(v)). Under (C-ii), for q in F ∩ [q_i, q_{i+1}] (inside D, outside (q_u, q_v)) and real s,
    H(q) + w q s <= T_i(q) + w q s <= max{h_i + w q_i s, h_{i+1} + w q_{i+1} s}, since T_i + w s q is affine in q.
    Since F is inside (q_0, mu] = union of the cells, for t in (0, 1]
        sup_{q in F} [q M(q) + w q (1 + log t)] = sup_{q in F} [H(q) + w q log t] <= max_i (h_i + w q_i log t).
(v) Hinge bound. Write l_i(s) = h_i + w q_i s, s = log t <= 0. By (C-iii), for j > k: l_j(s) <= l_k(s) when s <= 0
    (h_j <= h_k and w q_j > w q_k), so the max may be taken over i <= k. With l_{i+1}(s) - l_i(s) = D_i (s - r_i):
    max_{i<=k} l_i(s) <= l_0(s) + sum_{i<k} D_i (s - r_i)_+. Now int_0^1 l_0(log t) dt = h_0 - w q_0 and
    int_0^1 (log t - r)_+ dt = e^r - r - 1 for r <= 0, while for r > 0 the integral is 0 <= e^r - r - 1. Summing,
        CERT <= h_0 - w q_0 + sum_{i<k} D_i (e^{r_i} - r_i - 1) = h_k - w q_k + sum_{i<k} D_i e^{r_i}
    (telescoping: sum_{i<k} D_i (r_i + 1) = h_0 - h_k + w (q_k - q_0)).
    Integrability: the integrand t -> sup_{q in F} [H(q) + w q log t] is a supremum of affine functions of log t,
    finite (F bounded and nonempty), hence convex in log t and measurable; it is >= H(mu) + w mu log t (mu in F), which
    is integrable on (0, 1), and <= the integrable hinge function above. So CERT is defined and, by (C-iv), < 0. []

Remark (how the checkers evaluate H). Checker A evaluates H by ZBS's two-branch formula (1.2); checker B by the
representation in (iii). At a grid point where the comparison of A and B is not decided by the enclosures, checker A
takes the union of the two branch enclosures (H is continuous there). A grid point that is not certified inside D
makes the evaluation raise (refusal).

## 4. The certificate format (certK3.json, certCD3.json)

A certificate is one JSON object; every number is an exact rational written as a string "n/d" or "n" and parsed with
Python's fractions.Fraction (checker A) or flint.fmpq (checker B). A profile reference is a pair [kind, index] with kind
"zr"/"zc" (ZBS raw/closed profile) or "nr"/"nc" (new raw/closed profile); a source reference is ["z", h] or ["n", h]; a
control reference is an index into the new controls. Negative indices are refused (bankA.NList; checker B likewise).

- root: {closed: index of Q among new closed profiles, z: the claimed L_Q(1)}.
- controls: list of {p, mu, w, beta, x, lxU, l1mL} plus EITHER cert: {a_cut, q: [q_0..q_N], h: [h_0..h_N],
  sec: [[u_i, v_i] for each cell], k} (Lemma C, Section 3) OR lemmaD: {a_cut, a_hi, alpha, u_b, Dplus, y_c, G_up,
  P_up, qgrid, jA0, tree} (Lemma D, Section 7; certCD3 only). lxU and l1mL are ZBS's CtrlD fields: rationals with
  x <= e^{lxU}, e^{l1mL} <= 1 - mu and lxU < w l1mL, which together give x < (1 - mu)^w.
- raw: list of direct profiles {p, xs: knots, ys: values, min, pieces}. A piece is
  - a leaf {kind: "leaf", c, src, xi, nu, ys, aU, bU, margin, lo, hi, bp}, or
  - a retained route {kind: "route", t: {c, src, xi, nu, ys, aU, bU}, us: [u_0..u_M], ds: [d_1..d_M], g0, hm, margin,
    lo, hi, bp, calls: [{ch: child profile reference, z, bp} for each cell]}.
  Terminal data (c, src, xi, nu, ys, aU, bU) define the control gamma of Definition 5.2 with source index sigma = src,
  xi, nu as given, y0 = e^{-(B_sigma + ys)} (so B_gamma = B_sigma + ys exactly), and rational upper bounds
  aU >= A_gamma = -log xi, bU >= b_gamma = -log nu. bp lists the breakpoints at which the piece's inequalities are
  checked.
- closed: list of combined profiles {p, xs, ys, min, pieces}; a piece is {kind: "density", R, lo, hi, bp} or
  {kind: "pair", R, S, lo, hi, bp}, with R, S references to RAW profiles only.
- sources: list of new source pairs {A, B, Lo, Hi, eps, eta, kL, kR, cells}; kL, kR index ZBS's lines; a cell is
  {kind: "grounded", lo, hi, k} or {kind: "pair", lo, hi, PR, PB, bp}.

### 6.2 Proposition A.2 (one row, exact, finite r)

Let j in X with m_j > 0 and sigma'_j > 0; if j is in T assume Delta n_T sigma'_j >= 1 - c.
 (a) If q'_j > 0: r E_nu Z^T_j = avg_{i in B^T_j} phi_i.
 (b) If q'_j > 0 and BLUE_T(j) fails: E_nu (1 + Z^T_j)_+^s < U^T_j := (mu/(q'_j v))^{w beta}.
 (c) If RED_T(j) fails: with W_j = (1 - q'_j) + psi_T/r - q'_j Z^T_j,
       E_nu[h_j (W_j)_+^s] < (1 - q'_j)^{s - w beta} x^beta v^{-w beta} pi_j^{1 - beta}.
 (d) If q'_j > 0, m_j < 1 and both tests fail: with z_in = E_nu[Z^T_j | Y_j], z_out = E_nu[Z^T_j | Y \ Y_j],
       z_in > L^T_j,  where q'_j r L^T_j = (1 - q'_j) r (1 - e^{l^T_j/r}) + Psi_j(T),
       l^T_j = log x - w log v - w log(1 - q'_j) + beta^{-1}[(1 - beta) log pi_j - log m_j],
       m_j (1 + z_in)_+^s + (1 - m_j)(1 + z_out)_+^s < U^T_j,
     hence avg_{i in B^T_j} phi_i <= r S(m_j, U^T_j, L^T_j), where S(m, U, L) = sup{m z1 + (1-m) z2 : z1 >= L,
     m (1+z1)_+^s + (1-m)(1+z2)_+^s < U} is ZBS's two-cell supremum (Step 1 of the proof of Proposition 3.5, (4)).
 (e) If q'_j = 0 and RED_T(j) fails: m_j (1 + Psi_j(T)/r)_+^s < x^beta v^{-w beta} pi_j^{1 - beta}.
Proof. (a) b^T_j - g = avg_{i in B^T_j}(h_i - g), so Z^T_j = avg_{B^T_j} e_i; apply Lemma A.1.
(b) For nonempty B in X, Phi_c(B, Y)^beta = |B|^{w beta} M^beta E_Y (b - c)_+^s (H_c^{r beta} = H_c^s), and
Phi_c(X, Y)^beta = N^{w beta} M^beta H^s. With |B^T_j| = q'_j v N the failure reads
(q'_j v)^{w beta} E_Y (b^T_j - c)_+^s < mu^{w beta} H^s. Since b^T_j - c = u (1 + Z^T_j) and nu_y = u_y^s/(M H^s),

### 6.6 The failing sequence (Definition (INF))

Let 0 < p, mu, beta < 1, w > 0, 0 < x < min{p, (1 - mu)^w}, and let Lambda = (0 < v_1 < ... < v_m = 1) be a scale grid.

### 6.7 Theorem A.9 (per-row limit)

Let a failing sequence be given. Rank the rows by V decreasing, the i-th row having rank i/N; for a row j let
F_j(t) = |B_j ∩ {rank <= t}|/N; let phi_n(t) be the drift of the row of rank ceil(tN)/N (a nonincreasing step function).
Then along a subsequence there are d_* in [p, 1), a nonincreasing phi in L1(0, 1] with phi >= -w, int_0^1 phi = 0 and
Phi(v) := int_0^v phi <= -w v log v (0 < v <= 1), and a probability space of limit rows omega with a uniform rank
U(omega) and nondecreasing 1-Lipschitz profiles F_omega (F_omega(0) = 0), such that, with
    eta~_k := -w log v_k - Phi(v_k)/v_k  in [0, w log(1/v_k)],     g_{omega,k} := F_omega(v_k)/v_k,
for almost every omega:
 (B') for every k with v_k > U(omega): G0_{d_*}(g_{omega,k}) <= beta eta~_k and g_{omega,k} <= mu; in particular
      g_{omega,k} >= a_{d_*}(eta~_k) >= a(eta~_k);

Moreover (Step 6 below) E[int_0^1 phi dF_omega] = E[q_omega phi(U(omega))].
Proof.
Step 1 (regular rows). By ZBS (6) and (7) (Step 2 of the proof of Proposition 3.5), E_X |m_i - d_n| + E_X |pi_i - d_n| =
O(1/r), d_n = d_R(X_n, Y_n). By Lemma A.6(iii) applied to T_k and to X \ T_k, sup_k ||psi_{T_k}||_2 <= C for large r,
so |P_j(T_k)| <= C. Choose eps_n -> 0 with eps_n r_n -> infinity. Call j regular if |m_j - d_n|, |pi_j - d_n| <= eps_n
and q'_j(k) <= cap_n for every k with j in T_k. Non-regular rows are a proportion at most O(1/(eps_n r_n)) + m zeta_n
-> 0. For a regular j in T_k, sigma'_j(k) >= 1 - cap_n - 1/n_{T_k} > 0 and
Delta n_{T_k} sigma'_j >= Delta (v_1 N (1 - cap_n) - 1) >= 1 - c_n, so Proposition A.2 applies (the bracket condition is
guaranteed only for rows with q' <= cap_n, which is why regularity is defined with cap_n).
Step 2 (limit). Row features xi_j = (rank_j, F_j, m_j, pi_j, (P_j(T_k))_k, 1[j regular]) lie in a compact metric space
(F_j in the nondecreasing maps [0,1] -> [0,1] with the L1 metric, compact by Helly; P in [-C, C]). phi_n >= -w,
int_0^1 phi_n = 0 and int_0^t phi_n <= r t (t^{-w/r} - 1) (ZBS (1) with z = 1_{rank <= t}) make (phi_n) uniformly
integrable; by Helly a subsequence converges in L1(0, 1) to a nonincreasing phi with the stated properties
(Phi(v) <= -w v log v as the limit of r v (v^{-w/r} - 1)). Pass to a further subsequence with d_n -> d_* and with the
laws of xi_J (J uniform in X) convergent; d_* >= p, and d_* < 1 by Claim P1.6 (Section 14; ZBS Step 6) (the v = 1 tests are ZBS's (RED) and
(BLUE), and Proposition 3.5's hypotheses (i)-(iv) hold at v = 1, the failing RED_X(i) giving ZBS's (3) for rows with
q_i <= cap_n through Lemma 4.5's identity and the Delta bound; so ZBS Steps 1, 2, 5 and 6 apply;
Step 6 gives d_* <= [x/(1 - mu)^w]^{1/(1 + mu/(beta(1-mu)))} < 1).
Skorokhod represents the laws on ([0, 1], Leb) with xi^n(omega) -> xi(omega) a.s. In the limit U is uniform,
m = pi = d_*, the regularity indicator is 1 for all large n a.s., F_omega is 1-Lipschitz (F_j(t') - F_j(t) <= t' - t +
1/N), and P_omega(k) is in [-C, C].

|phi_n(i/N) - phi(i/N)| <= ||phi_n - phi||_1 + 2 (phi(1/N) + w)/N + int_0^{1/N} |phi| -> 0, because phi_n is constant

[0, a_{d_*}(eta~_k)). At v_m = 1 (T = X, Psi = 0, H^T_{1,d_*}(q, 0) = q M_{d_*}(q)) this is
int_0^1 phi dF_omega <= q_omega M_{d_*}(q_omega). q_omega > 0: q = 0 would need G0_{d_*}(0) = beta log(d_*/x) <= 0,
false since d_* >= p > x. So Proposition A.5 gives G < 0 at q_omega > 0, i.e. q_omega in F_{d_*} (F_{d_*} = {G0_{d_*} < 0}

Step 6 (the aggregate identity in the limit). At finite r, because the blue graph is undirected,
E_J[(1/N) sum_{i in B_J} phi_i] = (1/N^2) sum_i |B_i| phi_i = E_J[q_J phi_J] (J uniform in X). The left side converges

q <= 1, and E|phi(U^n) - phi(U)| -> 0 (phi is in L1 and continuous a.e., U^n -> U a.s., phi(U^n) uniformly
integrable). []

### 6.8 Theorem A

**Definitions.** Fix 0 < p, mu, beta < 1, w > 0, 0 < x < min{p, (1 - mu)^w} and a scale grid

0 <= eta_k <= w log(1/v_k) and Phi(v_k) <= -w v_k log v_k - v_k eta_k. With phi(1) the value at 1 (= the left limit),
Delta_k := phi(v_k) - phi(v_{k+1}) >= 0 for k < m, and F = F_p(x, mu), M = M_p:
    c(u) = sum_{k < m, v_k >= u} a(eta_k) v_k Delta_k,
    V_A(phi, eta) = int_0^1 sup{ q (M(q) - phi(u)) : q in F, q M(q) >= q phi(1) + c(u) } du    (sup of the empty set =
                                                                                                -infinity).
The integrand is a monotone function of (phi(u), c(u)) on each of the finitely many intervals where c is constant,
hence measurable.

**Theorem A.** If V_A(phi, eta) < 0 for every admissible (phi, eta), then (INF) holds for (p, mu, w, beta, x; Lambda).

                                          + (1 - kappa2h/kappa2) m_b (ph - y_sp)_+),
 IRs = int_{u_b}^1 Hhat+(phi_s), qB <= qhat(ph) <= qhat(p_b).

D7 (the box). K = int_0^{u_b} (phi* - s0)_+ has dK/dPhi_b in [0, 1] (exact difference formula on the switch interval;
(y - s0)_+ has slopes in [0, 1]), so K at min(Ph, g-) plus (g+ - g-) bounds it. When min(Ph, g-) = g-, a different bound
is used: phi* is nonincreasing with Phi* <= g = int phi_s and Phi*(0) = 0, so phi* is weakly submajorised by phi_s on
[0, u_b], and (. - s0)_+ is convex and nondecreasing, hence K <= int_0^{u_b} (phi_s - s0)_+ for every feasible Phi_b
(weak majorisation, Tomic-Weyl). q_R is the active slope of Hhat+ at the drift phi_s(b2) with b2 the upper end of the
u2-enclosure at P1 (u2 decreases in Phi_b, so phi_s(u2) >= phi_s(b2) for every Phi_b >= P1). IR2 uses
Phi** = min(g, Phi_b + p_b (. - u_b)). IL is nonincreasing in Phi_b and in p_b; K is nondecreasing in Phi_b and
nonincreasing in p_b; IR2 is nondecreasing in both (Lemma M and the switch-point argument). Explicitly: phi* = phi_s
on [0, u1) and = p_b on (u1, u_b], where u1 solves g(u1) = Phi_b - p_b (u_b - u1) with phi_s(u1) >= p_b; so
du1/dPhi_b = 1/(phi_s(u1) - p_b) > 0 and, differentiating IL = int_0^{u1} Psi_j0+(phi_s) + (u_b - u1) Psi_j0+(p_b) and
K = int_0^{u1} (phi_s - s0)_+ + (u_b - u1)(p_b - s0)_+,
    dIL/dPhi_b = [Psi_j0+(phi_s(u1)) - Psi_j0+(p_b)] / (phi_s(u1) - p_b)  in [-q_max, -q_min],
    dK/dPhi_b  = [(phi_s(u1) - s0)_+ - (p_b - s0)_+] / (phi_s(u1) - p_b)  in [0, 1]
(difference quotients of a convex nonincreasing function with slopes -q_j, and of (. - s0)_+). phi** = p_b on
[u_b, u2) and = phi_s on (u2, 1], where u2 solves Phi_b + p_b (u2 - u_b) = g(u2) with p_b >= phi_s(u2); so
du2/dPhi_b = -1/(p_b - phi_s(u2)) and, from IR2 = (u2 - u_b) Hhat+(p_b) + int_{u2}^1 Hhat+(phi_s),
    dIR2/dPhi_b = [Hhat+(phi_s(u2)) - Hhat+(p_b)] / (p_b - phi_s(u2))  <= q_R,
since phi_s(u2) >= phi_s(b2) for Phi_b >= P1. Monotonicity in p_b at fixed Phi_b is Lemma M: on [0, u_b], raising p_b
lowers Phi* = min(g, Phi_b - p_b (u_b - .)) pointwise with the same end values 0 and Phi_b, so IL and K (integrals of
convex functions of phi*) do not increase; on [u_b, 1], raising p_b raises Phi** = min(g, Phi_b + p_b (. - u_b))
pointwise with the same end values Phi_b and 0 (Phi_b + p_b (1 - u_b) >= Phi(1) = 0 because phi <= p_b there), so IR2
does not decrease. So, with
P1 = min(max(Pl, pl u_b), g(u_b)-),
    T(Phi) := IL(Phi, pl) + (1 - theta) IR2(Phi, ph) + theta (IRs - qB max(0, g- - Phi))
bounds every configuration of the box with Phi_b = Phi, and T(Phi') - T(Phi) <= (-q_min + (1 - theta) q_R + theta qB)
(Phi' - Phi) (exact difference formulas on the switch intervals; q_min = least slope of Psi_j0+, q_R = active slope of
Hhat+ at drift phi_s(u2)). Therefore
    U(B) = T(P1) + max(0, slope)(Ph - P1) + Delta0 K + kappa (E_grid + E_cap + E_high),  K at (min(Ph, g-), pl) + (g+ - g-),
bounds V_A for every admissible (phi, eta) whose pair lies in B. Switch points u1, u2 are enclosed by certified-sign
bisection; on the enclosure the integrand is bounded by its monotone end value. All integrals of max-of-lines along
phi_s are exact: with s = log t, h_j - q_j (w + phi_s(t)) = h_j + w q_j log t, the upper hull has rational breakpoints,
and int (c + d log t) dt = t (c + d (log t - 1)).

D8 (all scales). Theorem A's grid enters only through u_b and the mesh D, and the mesh terms are added explicitly in
U(B) (C0's D (ph + w), kappa E_grid, the D terms of E_cap). With D = (1 - u_b)/10^6 they are small but not negligible
against the tightest margins (kappa E_grid is about 1e-7 near the saturated profile); every checker adds them. []

### 7.4 Specification of U(B) (what every Lemma D checker computes; "X+" an upper and "X-" a lower bound)

Input box B = [Pl, Ph] x [pl, ph]; g-, g+ enclose g(u_b) = -w u_b log u_b. Node indices j in steps 1, 5, 6, 7 range over
j >= 1 (q_0 = a_cut need not lie in Q). Where a box "fails", the checker rejects the certificate.
0. Infeasible (U = -1): Pl > g+; pl u_b > Ph or pl u_b > g+; ph (1 - u_b) < -Ph; ph < -w.
1. C0 = a0 (w + u_b pl - Ph - D (ph + w)). j0 = least node j >= 1 with H(q_j)- >= C0 (fail if none);
   h1 = Ht'(q_j0)- + w (> 0); s0 = Ht'(q_j0)-; Delta0 = (H(q_j0)+ - C0)/h1. Psi+ = max over nodes j >= j0 of
   (h_j - q_j (w + y)).
2. P1 = min(max(Pl, pl u_b), g-) (fail if P1 < pl u_b). [a1, b1] encloses u1 for (P1, pl) (bisection, f = g - line).
   IL = int_0^{a1} Psi+(phi_s) + (b1 - a1) max(Psi+(pl), Psi+(phi_s(b1)-)) + (u_b - b1) Psi+(pl) (exact hull integral).
   Psi+ and Hhat+ are nonincreasing in y, so at an irrational argument such as phi_s(b1) the lower end of its enclosure
   is used (likewise phi_s(b2)- in step 4).
3. PK = max(min(Ph, g-), pl u_b). If PK < g-: [ak, bk] encloses u1 for (PK, pl). If PK = g-: [ak, bk] = [u_b, u_b],
   which gives K = int_0^{u_b} (phi_s - s0)_+ + (g+ - g-), valid for every feasible Phi_b by weak majorisation (D7).
   t0 = e^{-1 - s0/w}; Kint = -bk s0 - w bk log bk if bk <= t0 (certified), else w t0;
   K = Kint + (u_b - ak)(pl - s0)_+ + (g+ - g-).
4. [a2, b2] encloses u2 for (P1, ph) (f = line - g on [u_b, 1]; if f(1)+ < 0, take a2 = b2 = 1, see switch points).
   IR2 = (a2 - u_b) Hhat+(ph) + (b2 - a2) max(Hhat+(ph), Hhat+(phi_s(b2)-)) + int_{b2}^1 Hhat+(phi_s).
   IRs = int_{u_b}^1 Hhat+(phi_s).
5. y_sp = phi_s(u_b)+, y_top = min(ph, y_sp). jA = largest node j >= 1 with Ht'(q_j)- >= y_top (fail if none, if
   jA < jA0, or if jA = N); kappa2 = 1/max of |Ht''|+ over cells i >= jA; jB = largest node j >= 1 with
   Ht'(q_j)- >= ph, qB = q_jB (qB = a0 if none); kappa = alpha K/h1; theta = kappa/kappa2 (fail if > 1);
   m_b = (g- - P1)_+. theta is one number (any upper bound of kappa/kappa2 that is <= 1) used in both places of step 8.
6. q_R = (slope of the hull piece of Hhat+ at s = log(b2)+)/w; slope = -q_min(Psi+) + (1 - theta) q_R + theta qB;
   dvar = slope_+ (Ph - P1).
7. Lip = max(phi_s(u_b)+, ph) + w; E_grid = Lip D (ph - y_c)_+; E_cap = (y_c^2 - w^2)/2 + w^2 (1 - e^{-1 - y_c/w})
   + D (ph + w)(y_c + w); kappa2h = 1/max of |Ht''|+ over cells i >= jB (0 if jB is undefined, jB < jA0 or jB = N),
   capped at kappa2; E_high = (1 - kappa2h/kappa2)(g+ - P1)(ph - y_sp)_+.
8. U(B) = IL + Delta0 K + (1 - theta) IR2 + theta (IRs - qB m_b) + dvar + kappa (E_grid + E_cap + E_high).

### 7.5 Certificate format and checks K1-K10 (CERT_DESIGN Section 4c)

FORMAT. JSON; rationals as strings. Fields: control {p, mu, w, beta, x} (in certCD3 the checker uses the bank control's
own five fields); a_cut, a_hi, alpha, u_b, Dplus (= D), y_c, G_up, P_up; qgrid [q_0, ..., q_N]; jA0; tree. A tree node is
"L" (leaf) or [axis, child1, child2] with axis "P" or "p"; the root rectangle is [0, G_up] x [-w, P_up] in
(Phi_b, p_b); axis "P" splits [Pl, Ph] at the midpoint into [Pl, m] and [m, Ph], axis "p" splits [pl, ph] likewise. The
leaves cover the root rectangle by construction.
CHECKS (exact rationals, outward-rounded exp/log; every "<" or ">=" must hold for the whole enclosure):
 K1 0 < p < 1, 0 < mu < 1, w > 0, 0 < beta < 1, 0 < x < p, and x < (1 - mu)^w.
 K2 0 < a_cut < a_hi < mu; G0(a_cut) >= 0; G0(a_hi) < 0; G0(mu) < 0; G0'(a_hi) < 0; alpha >= beta/|G0'(a_hi)|.
 K3 0 < u_b < 1, D > 0, (1 - u_b)/D a positive integer.
 K4 N >= 2, q_0 = a_cut, q_N = mu, strictly increasing, q_1 >= a_hi (so q_1, ..., q_N are in Q).
 K5 node heights computed by the checker (not read from the file): on every cell some affine A_i with H <= A_i on
    Q ∩ [q_i, q_{i+1}], A_i(q_i) <= h_i, A_i(q_{i+1}) <= h_{i+1}; any tangent of the concave H at a point of Q works
    (Lemma C (iii)); cell 0 must use the tangent at q_1 (q_0 = a_cut is not in Q). Then Hhat+ and Psi_j0+ bound Hhat and
    the restricted sup as stated in 7.2.
 K6 1 <= jA0 <= N - 1; for every cell i >= jA0 an upper bound d2_i >= |Ht''| on [q_i, q_{i+1}] (both branch formulas
    where A - B changes sign on the cell; the cell certified in Q: G0(q_i)+ < 0 and G0(q_{i+1})+ < 0). At a node where the
    sign of A - B is not certified, H(q_j) and Ht'(q_j) are enclosed by the union of the two branch enclosures (Ht is C^1
    and H continuous across A = B, D0).
 K7 y_c > -w and y_c >= Ht'(mu).
 K8 phi_s(u_b) >= y_c (lower end of the enclosure).
 K9 G_up >= g(u_b) and P_up >= -w log u_b.
 K10 every leaf box B of the tree has U(B) < 0 by 7.4, or is infeasible by step 0.
SWITCH POINTS. u1 for (Phi, p) on [0, u_b]: f(u) = g(u) - (Phi - p (u_b - u)) is concave with f(0+) <= 0 (Phi >= p u_b)
and f(u_b) > 0 (Phi < g(u_b)); u1 = inf{u : f > 0 on (u, u_b]}; any [a1, b1] with a1 = 0 or f(a1)+ <= 0, and b1 = u_b or
f(b1)- > 0, encloses u1. u2 for (Phi, p) on [u_b, 1]: f(u) = Phi + p (u - u_b) - g(u) is convex with f(u_b) < 0;
[a2, b2] with f(a2)+ <= 0 (or a2 = u_b) and f(b2)- > 0 (or b2 = 1). If f(1) < 0 at (P1, ph), u2 is clipped to 1 and
IR2(P1) = (1 - u_b) Hhat+(ph); this is sound because for feasible Phi' > P1, IR2(Phi') - IR2(P1) =
int_{u2'}^1 [Hhat+(phi_s) - Hhat+(ph)] <= q_R int_{u2'}^1 (ph - phi_s) = q_R (Phi' + ph (1 - u_b)) <= q_R (Phi' - P1).
OTHER QUANTITIES. q_R may be any upper bound of the slope magnitudes of Hhat+ on [phi_s(b2), ph]; q_min(Psi+) any lower
bound of the slope magnitudes of Psi+ (e.g. q_j0); |Ht''| on a cell may be bounded by any rigorous method; bisection may
stop at any width. Any more conservative choice is sound.
Accept iff K1-K10 all hold.

### 7.6 The three Lemma D checkers

- checkD_A.py (code/lemmaD, SHA-256 3600766b...b9bc): Fractions with ivA.py (256-bit dyadic intervals); H, Ht', Ht''
  by hand-derived two-branch formulas; node heights by the right-end tangent; stack hull.
- checkD_B.py (code/lemmaD, SHA-256 3a748ce2...723a): python-flint 0.9.0 Arb/fmpq (pinned: other versions are refused);
  H through Lemma C (iii)'s representation with fbar, Ht' and Ht'' by Arb power series; heights by the better end
  tangent on cells i >= 1; gift-wrapping hull.
- checkD_C.py (research/tier2/ramsey-lemma/cert_independent, SHA-256 97369eab...ab1f05 at HEAD; code commit 0548347a0,
  results 9fe23c44f): written by a fresh author from CERT_DESIGN Sections 1-3, 4b and 4c only, without opening checkD_A,
  checkD_B or genD.
CODE AUDIT NOTES (referee 2). checkD_C checks K1-K10 explicitly. checkD_A and checkD_B do not test K4's N >= 2 or
K6's 1 <= jA0 <= N - 1 as such: certificates violating them are refused, but by unrelated exceptions;
tools/preflight.py now tests K4 and K6 explicitly (Section 5). Per box: jA = N ends in max() of an empty sequence where
7.4 step 5 says "fail" (a refusal either way); for jB = N, 7.4 step 7 sets kappa2h = 0, while checkD_A (line 352) and
checkD_B take a max over an empty range and refuse. That is a completeness issue, not a soundness one (the frozen
checkers refuse where the specification would compute U(B)), and it is never reached by the 26 accepted certificates.
The preflight cannot test these per-box conditions. checkD_A reads any tree axis other than "P" as "p" (a relabelled node is still a valid bisection; checkD_B and
checkD_C refuse it; the preflight refuses it). checkD_B sets 300 bits at its first import and ctlB restores 320 bits
afterwards, so later CD controls run at 320 bits; rigour is unaffected either way.
INDEPENDENCE. checkD_A and checkD_B are independent in arithmetic (interval systems, formulas for H and its
derivatives, hull and switch-point code) but were written by the same author from the same U(B) assembly (7.4), so an
error in D3-D7 would pass both. checkD_C is the independent implementation of that assembly; it is a standalone third
reading and is not wired into the bank checkers. Lemma C (iii) (concavity of H on Q), on which K5 rests, is proved, not
tested; as a cross-check outside acceptance, checkD_C's sanity_C.py certifies Ht'' < 0 by interval jets on every cell of
c1722_m300 except the one touching a(0).

### P1.1 Lemmas 3.1 and 3.2

Lemma 3.1 (columns). If (X, Y) is maximal and H > 0, then u_y >= (1 - beta)^{1/s} H > 0 for all y; hence
alpha >= (1 - beta)^{1/s} H.
Proof. For nonempty Y' in Y, Phi_c(X, Y') = N^w |Y'|^{1 - r/s} (sum_{y in Y'} (u_y)_+^s)^{r/s} with 1 - r/s < 0. If some
u_{y0} <= 0 and |Y| >= 2, deleting y0 keeps the sum (positive, as H > 0) and lowers |Y'|, strictly increasing Phi_c:
impossible. If |Y| = 1, u_y = H > 0. Let |Y| >= 2, fix y, a = u_y/H, so u_y^s/sum u^s = a^s/|Y|. Maximality at
Y \ {y}, raised to s/r: 1 - a^s/|Y| <= (1 - 1/|Y|)^{1 - s/r} <= 1 - (1 - beta)/|Y| (Bernoulli for the exponent
1 - s/r = 1 - beta in (0, 1)). So a^s >= 1 - beta. []

Lemma 3.2 (rows). If (X, Y) is maximal and H > 0, put V_v = E_Y[u_y^{s-1}(h_{vy} - c)]/H^s. Then E_X V_v = 1 and for every
z in [0, 1]^X with t = E_X z > 0,
    E_X[z_v V_v] <= t^{1 - w/r};                                                                    (1)
in particular V_v >= 1 - w/r for every v.
Proof. Averaging h_{vy} - c over v gives u_y, so E_X V = E_Y u^s/H^s = 1. For z in [0, 1]^X let b_y = E_X[z_v (h_{vy} - c)],
||vec||_s = (E_Y |vec_y|^s)^{1/s} for vectors vec indexed by Y, and Lambda(z) = t (||(b/t)_+||_s/H)^{r/w}, Lambda(0) = 0.
The map vec -> (||vec_+||_s/H)^{r/w} is convex (||vec_+||_s is convex and nonnegative, r/w > 1), so Lambda (its
perspective composed with a linear map) is convex on {t > 0}; b/t is a convex combination of the vectors (h_{v.} - c),
so Lambda(z) = O(t) and Lambda extends continuously by 0 to a convex function on [0, 1]^X. At a vertex z = 1_{X'}
(X' nonempty), b/t is the column density of X' minus c, so Lambda(1_{X'}) = (Phi_c(X', Y)/Phi_c(X, Y))^{1/w} <= 1. A

### P3.1 Lemma 5.8 (leaves and routes)

Lemma 5.8. For each leaf or route piece J of a direct profile P there are K_J >= 1 and D_J >= 1, depending only on the

### P4.1 Notation

A host is a red/blue colouring of the edges of a complete graph on a finite vertex set V. For disjoint nonempty X, Y,
d_R(X, Y) = e_R(X, Y)/(|X||Y|). N_R(v), N_B(v) are the red and blue neighbourhoods of v; deg_chi(v, Z) = |N_chi(v) ∩ Z|.
A candidate is an ordered pair (X, Y) of disjoint nonempty vertex sets; it is (k, l, t)-good if X ∪ Y contains a red
K_k, or X contains a blue K_t, or Y contains a blue K_l. For reals C >= 1, xhat, yhat in (0, 1) and an integer l >= 1,
a host satisfies Stop(C, xhat, yhat, l) if for every integer a >= 1 every proper subset Z of V with
|Z| >= C xhat^{-a} yhat^{-l} contains a red K_a or a blue K_l (ZBS's Definition 4.1).
For a continuous F on [0, 1] with F(0) = 0 put G_F(a, b) = max(a, b) F(min(a, b)/max(a, b)) for a, b > 0, and
    B_F = {(X, Y) in (0, 1)^2 : G_F(a, b) <= -a log X - b log Y for all a, b > 0}.
With F-hat(lambda) = F(lambda) on (0, 1] and lambda F(1/lambda) on [1, infinity) one has G_F(a, b) = b F-hat(a/b), so
(X, Y) is in B_F iff F-hat(lambda) <= A lambda + B for all lambda > 0, where A = -log X, B = -log Y. B_F is closed
downward: (X, Y) in B_F and X' <= X, Y' <= Y give (X', Y') in B_F.

### P4.2 Lemma A.1 (finite-host weighted candidate bound)

Lemma A.1. Fix w > 0 and x0, y0, xhat, yhat, mu0, p in (0, 1) with x0 < xhat, y0 < yhat and
    x0 < (1 - mu0)^w p^{1/(1 - mu0)}.
There is L0, depending only on these numbers, such that: for every C >= 1, every host, and every integer l >= L0 such
that the host satisfies Stop(C, xhat, yhat, l), every candidate (X, Y) with
    d_R(X, Y) >= p   and   |X|^w |Y| >= C^{w+1} x0^{-k} y0^{-l} mu0^{-w t}                               (A.1)
is (k, l, t)-good, for all integers k, t >= 1.

Proof. Step 0 (parameters, fixed before C, the host, k, l, t). Choose an integer r > max{1, w} with p^{1/r} > mu0 and
    x0 < (p^{1/r} - mu0)^r (1 - mu0)^{w - r}.                                                       (A.2)
This is possible: p^{1/r} - mu0 = (1 - mu0) + (log p)/r + O(r^{-2}), so the logarithm of the right side of (A.2) is
r log(1 - mu0) + (log p)/(1 - mu0) + O(1/r) + (w - r) log(1 - mu0), which tends to log((1 - mu0)^w p^{1/(1 - mu0)}),
strictly above log x0. For x, mu in (0, 1) put phi_{x,mu}(q) = x^{1/r} (1 - q)^{1 - w/r} + mu^{w/r} q^{1 - w/r} on
[0, 1]. (A.2) raised to the power 1/r says phi_{x0,mu0}(mu0) = x0^{1/r}(1 - mu0)^{1 - w/r} + mu0 < p^{1/r}. Since
1 - w/r > 0, phi_{x0,mu0}'(q) has the sign of mu0^{w/r} q^{-w/r} - x0^{1/r}(1 - q)^{-w/r}, which is >= 0 iff
q <= mu0/(mu0 + x0^{1/w}); this threshold exceeds mu0 because x0 < (1 - mu0)^w. So phi_{x0,mu0} is increasing on
[0, mu0] and max_{[0, mu0]} phi_{x0,mu0} < p^{1/r}. The map (x, mu, beta) -> max_{[0, beta]} phi_{x,mu} is continuous,
so we can choose x0 < x < xhat, y0 < y < yhat, mu0 < mu < beta < 1, 0 < delta < p/2 and gamma > 0 with
    max_{0 <= q <= beta} phi_{x,mu}(q) <= (1 - gamma) pbar^{1/r},   pbar := p - delta.                      (A.3)
Put kappa0 = inf_{n >= 2} c^n/n^r > 0 with c = min{x/x0, (mu/mu0)^w} > 1, and a constant c1 > 0 with
xhat/x >= e^{w c1}, yhat/y >= e^{w c1} and 1/mu >= e^{c1} (possible since all three exceed 1).

Step 1 (a stronger statement). For n = k + t put delta_n = delta/n. We prove by induction on n, for fixed l >= L0 (L0
chosen at the end), the statement
  (I_n) every candidate (X, Y) with d_R(X, Y) >= p - delta_n and
        Q_n(X, Y) := (d_R(X, Y) - p + delta_n)^r |X|^w |Y| >= C^{w+1} x^{-k} y^{-l} mu^{-w t}
        is (k, l, t)-good.
(A.1) implies the hypothesis of (I_n): d_R >= p gives d_R - p + delta_n >= delta/n, so Q_n >= (delta/n)^r |X|^w |Y| >=
C^{w+1} x^{-k} y^{-l} mu^{-wt} times (delta/n)^r (x/x0)^k (y/y0)^l (mu/mu0)^{wt} >= delta^r kappa0 (y/y0)^l, which is
>= 1 once (y/y0)^l delta^r kappa0 >= 1 (a condition on L0). If k = 1 or t = 1, any vertex of X is a red K_1 or a blue
K_1, so the candidate is good. Let k, t >= 2 (so n >= 4) and assume (I_{n'}) for n' < n.

Step 2 (regularise; stop if Y is large). Delete from X, one at a time, vertices with fewer than (p - delta_n)|Y| red
neighbours in Y. With E = e_R(X, Y) - (p - delta_n)|X||Y| we have Q_n = E^r |X|^{w - r} |Y|^{1 - r}; a deletion
increases E and decreases |X|, and w - r < 0, so Q_n does not decrease. Q_n > 0 gives E > 0, so some vertex has more
than (p - delta_n)|Y| red neighbours and is never deleted: X stays nonempty. Goodness of the new pair implies goodness
of the old one. Now every nonempty T in X has d_R(T, Y) >= p - delta_n. If |Y| >= C xhat^{-k} yhat^{-l}: Y is a proper
subset of V (X is nonempty and disjoint from Y), and Stop with a = k gives a red K_k or a blue K_l in Y. Otherwise,
since Q_n <= |X|^w |Y|,
    |X|^w > C^w (xhat/x)^k (yhat/y)^l mu^{-w t},  hence  |X| >= C e^{c1 (k + l + t)} >= e^{c1 (n + l)}.          (A.4)

Step 3 (constants of the book step). Put
    b = ceil((2 r log n + r log(1/delta) + w log 2)/(w log(beta/mu))),  m = ceil(10 b^2/beta),  xi_n = delta/(2 n^2),
W = {v in X : deg_B(v, X) >= beta |X|}. We need
    |X| >= 5 m^2,   R(k, m) < pbar xi_n |X|,   2 n^2/(delta |X|) < gamma.                                    (A.5)
b = O(log n), m = O((log n)^2) and R(k, m) <= binom(k + m - 2, m - 1) <= n^{m - 1} = e^{O((log n)^3)} (ES; the binomial
counts multisets of size m - 1 from k symbols, at most k^{m-1} <= n^{m-1}), so each lower bound on |X| required by
(A.5) is at most e^{K0 (log n)^3} for a constant K0 (n >= 4, so log n > 1 and K0 absorbs additive constants); by (A.4) it suffices that
c1 (n + l) >= K0 (log n)^3 for all n >= 4, which holds for all l >= L0 with L0 large. So (A.5) holds.

Step 4 (many high blue degrees: a blue book). Suppose |W| >= R(k, m). Then W contains a red K_k (done) or a blue
clique U with |U| = m. Each u in U has at least beta |X| - m blue neighbours in X \ U, so the blue density sigma between
U and X \ U satisfies sigma >= (beta |X| - m)/(|X| - m) = beta - (1 - beta) m/(|X| - m) >= beta - 1/(4m) (as
|X| - m >= 4 m^2 by (A.5)). Pick a uniformly random b-subset S of U and let T be the set of vertices of X \ U joined in
blue to all of S. If z in X \ U has j_z blue neighbours in U, then Pr(z in T) = binom(j_z, b)/binom(m, b); the
piecewise-linear extension of j -> binom(j, b) is convex and nondecreasing, and the average of j_z is sigma m, so
E|T| >= (|X| - m) binom(floor(sigma m), b)/binom(m, b) >= (|X| - m)(sigma - b/m)^b (each factor
(floor(sigma m) - i)/(m - i), 0 <= i < b, is at least sigma - b/m > 0). Since m >= 10 b^2/beta,
sigma - b/m >= beta - beta/(40 b^2) - beta/(10 b) >= beta (1 - 1/(8b)), so by Bernoulli (sigma - b/m)^b >= (7/8) beta^b,
and |X| - m >= (4/5)|X|; hence E|T| >= (7/10) beta^b |X|. Fix S with |T| >= beta^b |X|/2; S is a blue b-clique, all
S-T edges are blue, S ∩ T is empty. If b >= t, S contains a blue K_t in X. If b < t: delta_{n-b} - delta_n >= delta/n^2,
and d_R(T, Y) >= p - delta_n (Step 2), so d_R(T, Y) - p + delta_{n-b} >= delta/n^2 and
    Q_{n-b}(T, Y) >= (delta/n^2)^r 2^{-w} beta^{w b} |X|^w |Y| >= (delta/n^2)^r 2^{-w} beta^{wb} Q_n >= mu^{wb} Q_n
                 >= C^{w+1} x^{-k} y^{-l} mu^{-w(t - b)},
using Q_n <= |X|^w |Y| and (beta/mu)^{wb} >= 2^w (n^2/delta)^r (the choice of b). By (I_{n-b}), (T, Y) is
(k, l, t - b)-good; a blue K_{t-b} in T together with S is a blue K_t in X, and the other outcomes are outcomes.

Step 5 (few high blue degrees: one vertex). Suppose |W| < R(k, m) < pbar xi_n |X|. Let Y_v = N_R(v) ∩ Y,
d = d_R(X, Y) and E0 = e_R(X, Y) >= pbar |X||Y| (Step 2: every row has at least (p - delta_n)|Y| >= pbar |Y| red
neighbours). Counting through Y and Cauchy-Schwarz:
    sum_{v in X} d_R(X, Y_v) |Y_v| = (1/|X|) sum_{y in Y} deg_R(y, X)^2 >= E0^2/(|X||Y|) = d E0.
The terms with v in W total at most |W||Y| < pbar xi_n |X||Y| <= xi_n E0, so
sum_{v not in W} d_R(X, Y_v)|Y_v| > (d - xi_n) E0 >= (d - xi_n) sum_{v not in W} |Y_v|, and some v not in W has
d_R(X, Y_v) >= d - xi_n (with |Y_v| >= pbar |Y| > 0). Put Y' = Y_v, X_R = N_R(v) ∩ X, X_B = N_B(v) ∩ X,
a = |X_R|/|X|, q = |X_B|/|X|, so a + q = 1 - 1/|X| and q < beta (v not in W). Put
alpha = d_R(X, Y') - p + delta_{n-1} >= (d - p + delta_n) + (delta_{n-1} - delta_n - xi_n) >= d - p + delta_n + delta/(2n^2)
> 0, and for chi in {R, B}: alpha_chi = d_R(X_chi, Y') - p + delta_{n-1} if X_chi is nonempty, alpha_chi = 0 otherwise;
Q_chi = (alpha_chi)_+^r |X_chi|^w |Y'|. Counting the red edges between X = {v} ∪ X_R ∪ X_B and Y' (v is red to all of
Y') gives d_R(X, Y') = a d_R(X_R, Y') + q d_R(X_B, Y') + 1/|X|; subtracting (p - delta_{n-1})(a + q + 1/|X|),
    alpha = a alpha_R + q alpha_B + (1 - p + delta_{n-1})/|X|,  so  1 <= a (alpha_R)_+/alpha + q (alpha_B)_+/alpha + 1/(alpha |X|)
(1 - p + delta_{n-1} <= 1 as delta < p/2). Claim: Q_R >= x Q_n or Q_B >= mu^w Q_n. If both fail, use
Q_n <= alpha^r |X|^w |Y| (alpha >= d - p + delta_n) and |Y'| >= pbar |Y|: (alpha_R)_+/alpha < (x/pbar)^{1/r} a^{-w/r}
(if a > 0) and (alpha_B)_+/alpha < (mu^w/pbar)^{1/r} q^{-w/r} (if q > 0); terms with a = 0 or q = 0 vanish. Then
    1 < pbar^{-1/r} {x^{1/r} a^{1 - w/r} + mu^{w/r} q^{1 - w/r}} + 1/(alpha |X|)
      <= pbar^{-1/r} phi_{x,mu}(q) + 2n^2/(delta |X|) <= (1 - gamma) + 2n^2/(delta |X|) < 1
(a <= 1 - q and 1 - w/r > 0; (A.3) with q < beta; alpha >= delta/(2n^2); (A.5)), a contradiction. If Q_R >= x Q_n, then
Q_R > 0 so alpha_R > 0, i.e. d_R(X_R, Y') > p - delta_{n-1}, and Q_{n-1}(X_R, Y') = Q_R >= x C^{w+1} x^{-k} y^{-l}
mu^{-wt} = C^{w+1} x^{-(k-1)} y^{-l} mu^{-wt}: by (I_{n-1}) with targets (k - 1, t), (X_R, Y') is (k - 1, l, t)-good,
and a red K_{k-1} in X_R ∪ Y' together with v (red to all of X_R and Y') is a red K_k in X ∪ Y; the other outcomes
are outcomes. If Q_B >= mu^w Q_n, then likewise Q_{n-1}(X_B, Y') >= C^{w+1} x^{-k} y^{-l} mu^{-w(t-1)}: by (I_{n-1})
with targets (k, t - 1), a blue K_{t-1} in X_B together with v (blue to all of X_B) is a blue K_t in X.

Step 6 (L0). L0 is any integer with (y/y0)^{L0} delta^r kappa0 >= 1 and c1 (n + L0) >= K0 (log n)^3 for all

### P4.3 Corollary A.2 (local density bound)

Corollary A.2. Fix w > 0 and mu, p, x, y, xhat, yhat in (0, 1) with x < xhat, y < yhat and
x < (1 - mu)^w p^{1/(1 - mu)}. There is L1 = L1(w, mu, p, x, y, xhat, yhat) such that for every C >= 1, every integer

the host contains a red K_k or a blue K_l.

### P4.4 Lemma B.1' (source criterion for one fixed epsilon)

Lemma B.1'. Let F: [0, 1] -> R be continuous with F(0) = 0, C^1 and concave on (0, 1], with F' > 0 on (0, 1]. Let
eps > 0 and alpha in (0, 1) with h(alpha) < eps/2. Suppose that for every s in [alpha, 1] there are w > 0 and
mu, Y in (0, 1) such that, with p0(s) = 1 - e^{-F'(s)} and X = (1 - mu)^w p0(s)^{1/(1 - mu)}, the pair (X, Y) is in B_F and
    (w + 1) F(s) + log X + s log Y + w s log mu > 0.                                                (B.1)
Then there is C_eps >= 1 such that for all integers a, b >= 1 and N >= C_eps exp(G_F(a, b) + eps(a + b)), every host
of order N contains a red K_a or a blue K_b.
(Lu and Wang assume (B.1) for all s in (0, 1] and conclude for every eps; their proof uses, for a given eps, only
s >= alpha with h(alpha) < eps/2, which is what is stated here.)

Proof. F >= 0 on [0, 1] (F(0) = 0, F' > 0). For x, y in (0, 1), mu in (0, 1), w > 0 put
H_{x,y}(t) = (-log x + t(-log y - w log mu))/(w + 1); (B.1) says H_{X,Y}(s) < F(s).

ybar = e^{-eps} Y. Then H_{xbar,ybar}(s0) = H_{X,Y}(s0) + eps(1 + s0)/(w + 1) < F(s0) + eps(1 + s0). Choose
x < xhat < xbar, y < yhat < ybar and p < p0(s0), so close to (xbar, ybar, p0(s0)) that x < (1 - mu)^w p^{1/(1 - mu)} (the
right side tends to X > xbar as p -> p0(s0)) and H_{x,y}(s0) < F(s0) + eps(1 + s0). F, F' are continuous at s0 > 0, so
there are an open neighbourhood O(s0) and eta(s0) > 0 with H_{x,y}(s) < F(s) + eps(1 + s) and p0(s) > p + 2 eta(s0) for
s in O(s0) ∩ [alpha, 1]. Every selected pair satisfies
    -a log xhat - b log yhat >= G_F(a, b) + eps(a + b)   (a, b > 0),                                     (B.2)
because -log xhat > -log X + eps, -log yhat > -log Y + eps and G_F(a, b) <= -a log X - b log Y ((X, Y) in B_F).
[alpha, 1] is compact: finitely many O(s0) cover it; let eta > 0 be the least eta(s0) and L >= 2 the largest of the
thresholds L1 of Corollary A.2 for the finitely many local bounds (independent of C).
Constants. Choose an integer K with alpha K >= L, and C_eps = C >= max{3, 2/eta, 4^K}.
Smallest counterexample. Suppose some host of order N >= C exp(G_F(a, b) + eps(a + b)) has no red K_a and no blue K_b;
take one of least order N over all pairs (a, b) and all such hosts. Rename the colours if needed (G_F is symmetric) so
that the targets are (k, l) with k >= l; then G_F(k, l) = k F(l/k).
- If k < K: by (ES), R(k, l) <= binom(k + l - 2, k - 1) <= 2^{k + l} <= 4^K <= C <= N, a contradiction.
- If s := l/k <= alpha: log R(k, l) <= log binom(k + l, l) <= k h(s) <= k h(alpha) < eps k/2 <=
  k F(s) + eps(k + l) + log C (F >= 0), so R(k, l) <= N, a contradiction.
- So s in [alpha, 1] and l = sk >= alpha K >= L. Take the local bound (w, mu, x, y, xhat, yhat, p) selected at a point
  whose neighbourhood contains s. Stop(C, xhat, yhat, l) holds: a proper subset Z with |Z| >= C xhat^{-a} yhat^{-l}
  has |Z| >= C exp(G_F(a, l) + eps(a + l)) by (B.2), and has smaller order, so by minimality it contains a red K_a or
  a blue K_l.
  - If the host's red density is at least p0(s) - eta (> p + eta > p): N >= C exp(k F(s) + eps(k + l)) >
    C exp(k H_{x,y}(s)) = C x^{-k/(w+1)} (y mu^w)^{-l/(w+1)}, and Corollary A.2 (l >= L) gives a red K_k or a blue K_l,
    a contradiction.
  - Otherwise the blue density exceeds q := e^{-F'(s)} + eta (< 1). Some vertex v has blue degree at least
    q (N - 1) = N e^{-F'(s)} + (eta N - q) > N e^{-F'(s)} (eta N >= 2 > q). Let Z be its blue neighbourhood.
    Concavity gives F(s - 1/k) <= F(s) - F'(s)/k, so
        |Z| > N e^{-F'(s)} >= C exp(k F(s) - F'(s) + eps(k + l)) >= C exp(k F((l - 1)/k) + eps(k + l - 1))
          = C exp(G_F(k, l - 1) + eps(k + l - 1))
    (l - 1 <= k). If l = 1 the host itself contains a blue K_1; otherwise Z, of smaller order, contains a red K_k or a
    blue K_{l-1} by minimality, and a blue K_{l-1} in Z together with v is a blue K_l. A contradiction.
Hence there is no counterexample. []

### P4.5 Lemma (concavity of f-hat and its conjugate)

Lemma P4.5. Let f be continuous on [0, 1], f(0) = 0, C^1 on (0, 1] and piecewise C^2 with f'' < 0 on every piece,
f'(t) -> +infinity as t -> 0+, and 2 f'(1) > f(1), f'(1) > 0. Then:
 (i) f-hat is strictly concave on (0, infinity) and increasing (its one-sided derivatives are positive everywhere);
 (ii) for A > 0, b(A) := sup_{lambda > 0} (f-hat(lambda) - A lambda) is finite, positive, and attained at a unique
      lambda*(A); lambda*(A) is nonincreasing and continuous in A, and b is convex, decreasing and C^1 with
      b'(A) = -lambda*(A);
 (iii) (e^{-A}, e^{-b(A)}) is in B_f for every A > 0 (both coordinates in (0, 1) because A > 0 and b(A) > 0);
 (iv) on the three branches: if A >= f'(1) then lambda* = t solves f'(t) = A and b = f(t) - t f'(t); if
      A <= f(1) - f'(1) then lambda* = 1/u where psi(u) := f(u) - u f'(u) = A, and b = f'(u); if
      f(1) - f'(1) <= A <= f'(1) then lambda* = 1 and b = f(1) - A.
(Without the hypothesis f'(0+) = +infinity the lemma can fail: for f(t) = 4t - t^2 and A = 5 the supremum is 0 and not
attained.)
Proof. (i) f is concave on [0, 1] (C^1 with nonincreasing derivative, continuous at 0) and strictly so (f'' < 0 on
pieces). On [1, infinity), d^2/dlambda^2 [lambda f(1/lambda)] = f''(1/lambda)/lambda^3 < 0 on pieces, and the derivative
f(1/lambda) - f'(1/lambda)/lambda is continuous; so f-hat is strictly concave on [1, infinity). At lambda = 1 the left
derivative f'(1) exceeds the right derivative f(1) - f'(1) (since 2 f'(1) > f(1)), so f-hat is strictly concave on
(0, infinity). f' >= f'(1) > 0 on (0, 1]; on (1, infinity) the derivative is psi(1/lambda) with psi(u) = f(u) - u f'(u)
(u = 1/lambda in (0, 1)), and psi(u) > 0: the tangent line of the strictly concave f at u lies strictly above f at 0,
i.e. f(0) = 0 < f(u) - u f'(u); at 1 both one-sided derivatives, f'(1) and f(1) - f'(1) = psi(1) > 0, are positive.
(ii) phi(lambda) = f-hat(lambda) - A lambda is continuous and strictly concave on (0, infinity), phi(lambda) -> f(0) = 0
as lambda -> 0+, phi(lambda) -> -infinity as lambda -> infinity (f-hat(lambda)/lambda = f(1/lambda) -> 0), and
phi > 0 on some (0, lambda0) because phi'(lambda) = f'(lambda) - A > 0 for small lambda (f'(0+) = +infinity). So
sup phi > 0 is attained in (0, infinity), at a unique point lambda*(A) by strict concavity; b(A) = phi(lambda*) > 0.
b is a supremum of affine functions of A, hence convex. Monotonicity (exchange argument): for A1 < A2, optimality of
lambda*(A1) at A1 and of lambda*(A2) at A2 gives, after adding the two inequalities,
(A2 - A1)(lambda*(A1) - lambda*(A2)) >= 0, so lambda* is nonincreasing. Danskin: for A in a compact [A1, A2] the
maximisers lie in the compact [lambda*(A2), lambda*(A1)], the function (A, lambda) -> f-hat(lambda) - A lambda is
continuous with A-derivative -lambda, and the maximiser is unique, so b is differentiable with b'(A) = -lambda*(A). A
differentiable convex function is C^1, so lambda* = -b' is continuous. (iii) f-hat(lambda) <= A lambda + b(A) for all
lambda > 0 by the definition of b; this is (e^{-A}, e^{-b(A)}) in B_f (P4.1). (iv) The maximiser satisfies 0 in the
superdifferential of phi at lambda*: on (0, 1) this is f'(lambda*) = A, on (1, infinity) it is psi(1/lambda*) = A, and
lambda* = 1 iff f(1) - f'(1) <= A <= f'(1). The values of b follow by substitution (on the right branch,
b = lambda* f(u) - A lambda* = (f(u) - psi(u))/u = f'(u)). []
